\## Project Description

EventPulse is a full-stack Event Management System built with React JS, Node.js, Express and MongoDB.



\## Installation Guide 



\### Frontend

1\. Extract the zip file

2\. Open terminal in the frontend folder

3\. Run: npm install

4\. Run: npm start

5\. App opens at: http://localhost:3000((**For Code Review Only**)





\### Backend

1\. Open terminal in the backend folder

2\. Run: npm install

3\. Create .env file with:

&#x20;  - MONGO\_URI=your\_mongodb\_connection\_string

&#x20;  - JWT\_SECRET=your\_secret\_key

4\. Run: npm run dev
